# TIMEWEAVE — History Reimagined

> **An immersive digital heritage experience that lets people explore historical worlds as living environments.**

TIMEWEAVE is a cinematic web experience centered on **Hampi during the Vijayanagara Empire**, combining interactive storytelling, timelines, reconstructed environments, and 3D-inspired interfaces.

## 🏛️ Experience

The prototype guides visitors through a structured historical journey:

1. **The Awakening** — cinematic introduction
2. **Choose a World** — select a historical setting
3. **The Time Machine** — navigate across historical periods
4. **Time Shift** — transition into the selected era
5. **Enter Hampi** — explore reconstructed locations
6. **Human History** — experience history through different roles
7. **Talk to History** — prototype historical guide
8. **Memory of Stone** — explore archaeological fragments
9. **Past vs Present** — compare reconstruction and present-day heritage
10. **Conservation & Future** — connect experience with preservation

## ✨ Technical Highlights

- 2.5D / 3D-inspired interactive environments
- Canvas-based particle and cinematic effects
- Interactive timeline and transitions
- Mouse-reactive camera/parallax effects
- Browser-synthesized ambient audio using Web Audio API
- Inline SVG fallbacks for resilient visual rendering
- Static architecture with no required backend
- GitHub Pages-compatible production build

## 🛠️ Tech Stack

**Frontend:** React, TypeScript, Vite  
**Experience:** HTML5 Canvas, CSS 3D, Web APIs  
**Audio:** Web Audio API  
**Deployment:** Static hosting / GitHub Pages

## ⚡ Run Locally

### Prerequisites

- Node.js 18+
- npm

### Install

```bash
npm install
```

### Development

```bash
npm run dev
```

Open the local Vite development URL shown in your terminal.

### Production build

```bash
npm run build
```

The production bundle is generated in `dist/`.

## 🧭 Design Philosophy

TIMEWEAVE treats digital heritage as an **experience rather than a static information page**.

The interface is designed around:

**Discover → Travel through time → Explore → Understand → Preserve**

## 📜 Historical Reconstruction Note

Historical reconstructions are **interpretive visualizations**, not exact archaeological reconstructions. The project presents an experiential interpretation based on available historical and heritage references.
